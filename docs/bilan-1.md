# Bilan de la séance 1

Copilot m’a aidé à comprendre le parcours des offres, à ajouter le filtre par période et à écrire les tests. J’ai appris comment le filtre passe de l’interface React à la requête SQL du backend.

Avec l’aide de ChatGPT, j’ai relu les modifications et demandé de renforcer les tests. J’ai testé les quatre choix avec les profils administrateur et étudiant : le filtrage fonctionne et les règles de visibilité sont conservées.

La principale difficulté a été un plantage de la copie des migrations sous Windows. Copilot a proposé une copie fichier par fichier. Après correction, npm run check réussit avec 117 tests backend et 47 tests frontend.

Crédits Copilot : 0 % utilisé au début, 4 % à la fin, soit une hausse de 4 points du quota affiché.
